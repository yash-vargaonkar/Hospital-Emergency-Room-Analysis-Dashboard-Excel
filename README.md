Hospital Emergency Room Analysis Dashboard | Excel
📊 Project Overview

The Hospital Emergency Room Analysis Dashboard is an Excel-based data analytics project designed to analyze emergency room patient data and provide useful insights for improving operational efficiency and patient services.

The project follows an end-to-end data analytics workflow, from understanding business requirements and preparing the data to developing an interactive dashboard and generating insights.

🎯 Project Objective

The objective of this project is to analyze hospital emergency room data and help stakeholders:

Monitor patient volume
Analyze patient waiting times
Evaluate patient satisfaction
Understand admission patterns
Analyze patient demographics
Identify frequently referred departments
Monitor patient attendance/timeliness

The dashboard is designed to support data-driven decision-making in emergency room operations.

📈 Dashboard KPIs
1. Number of Patients

Tracks the number of patients visiting the emergency room and uses a daily trend to identify patterns.

2. Average Wait Time

Measures the average time patients wait to see a medical professional and tracks daily changes.

3. Patient Satisfaction Score

Measures average patient satisfaction and helps identify changes in service quality.

📊 Analysis Included

Patient Attend Status / Timeliness
Gender Analysis
Department Referrals
🧮 DAX Calculations

The project uses DAX to create analytical categories such as Age Group and Patient Attend Status.

For example, patient wait time is classified into attendance status based on whether the wait time is below 30 minutes.
